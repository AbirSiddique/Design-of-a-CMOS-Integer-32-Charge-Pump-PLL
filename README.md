# Design-of-a-CMOS-Integer-32-Charge-Pump-PLL
This project presents a 1.28 GHz integer-32 charge pump PLL designed in 45 nm CMOS using a 40 MHz reference and divide by 32 feedback. The design includes a PFD, charge pump, loop filter, current starved VCO, and TSPC divider, verified through simulation and layout.
